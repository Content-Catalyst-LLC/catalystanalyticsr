# Catalyst Analytics R v2.2.0 — Statistical Diagnostics & Validation Contract

This release adds `sc.analytics-r.statistical-diagnostics-validation.v1`. It standardizes diagnostic metrics, assumption evidence, robustness evidence, model-comparison evidence, and validation bundles for downstream Core provenance and reasoning.

The release preserves the Workspace execution boundary, forbids automatic scientific-validity certification, and keeps forecasting in `projection_only` status until the predictive-runtime sequence.
