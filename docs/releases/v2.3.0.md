# Catalyst Analytics R v2.3.0

## Uncertainty & Sensitivity Runtime

Adds the bounded `sc.analytics-r.uncertainty-sensitivity-runtime.v1` contract, Monte Carlo and Latin hypercube runtime requests, Morris screening, Sobol first/total-order sensitivity, Core-ready evidence bundles, JSON serialization, provider capability promotion, and WordPress contract mapping.

No arbitrary R dispatch is introduced. Structured methods enforce evaluation budgets and canonical-scenario execution. Uncertainty/sensitivity outputs require human interpretation and do not establish causality, scientific validity, truth, or policy preference.
