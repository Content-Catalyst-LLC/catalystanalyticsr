# Catalyst Analytics R v2.0.1 — Release Contract Repair

Released as a patch-level contract and integration repair on 2026-09-21.

## Changes

- Corrects the stale release-readiness package version and release example.
- Aligns package/repository metadata and compatibility reporting with v2.0.1.
- Adds `workspace` to the governed Sustainable Catalyst handoff targets.
- Adds `workspace_handoff()` to express a host-managed R execution request without embedding transport or orchestration inside the R package.
- Keeps Connected Platform and Connected API contract versions at 2.0.0.
- Keeps the WordPress companion at v3.0.0 while mapping it to repository v2.0.1.

## Execution boundary

Catalyst Analytics R remains the statistical/sustainability analytical provider. Sustainable Catalyst Workspace owns runtime execution, isolation, resource policy, authentication, persistence, and job lifecycle. Returned results require validation and human review before publication or decision use.
