# Catalyst Analytics R v2.1.0 — Core Computational Provider Contract

Catalyst Analytics R 2.1.0 implements the provider side of Platform Core 3.1.0's `sc.core.analytical-runtime-provider.v1` contract.

## Added

- Runtime-provider manifest for `catalystanalyticsr` (`runtime=r`, `execution_host=workspace`).
- Twelve governed analytical capability declarations aligned with Platform Core 3.1.0.
- Core analytical request normalization and validation.
- Whitelisted execution plans; arbitrary function dispatch is explicitly forbidden.
- Workspace execution envelopes that require environment capture and input-reference resolution.
- Core-compatible result envelopes with output, estimate, uncertainty, diagnostic, and artifact references.
- JSON round-trip helpers for requests and results.
- Public API discovery for `/v1/core/provider` and validation for `/v1/core/requests/validate`.

## Runtime boundary

Platform Core declares and records analytical work but does not execute R. Workspace owns authentication, resource policy, runtime isolation, durable job state, input resolution, and environment capture. Catalyst Analytics R owns its analytical methods and provider-side contracts.

## Compatibility note

Platform Core 3.1.0 seeded provider version 2.0.1. Analytics R 2.1.0 remains contract-compatible with Core 3.1.0 and reports its actual 2.1.0 package version in provider/result provenance. The next Core integration release should update the registry record to 2.1.0 rather than mutating Core 3.1.0's release seed in place.

## Forecasting scope

The `forecasting` capability is represented as governed scenario projection in 2.1.0. Generic statistical forecasting, probabilistic calibration, and backtesting remain part of the later predictive-runtime sequence.
